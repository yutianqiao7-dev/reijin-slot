# L 覚醒スロット REIJIN

スマホのブラウザで遊べる、オリジナルのスマスロ風シミュレーターです。本物のお金は使いません。

**遊ぶ:** https://yutianqiao7-dev.github.io/reijin-slot/

- 押し順ベル・リプレイ・チェリー・スイカ・チャンス目、最大4コマ滑りのリール制御
- 通常時：高確・周期抽選・前兆・CZ・モード別天井・フリーズ
- AT（セット＋決戦バトル型）、上位AT、BONUS、上乗せ特化ゾーン、引き戻し、有利区間
- 演出：カットイン、ステップアップ、セリフ予告、消灯、役物落下、枠ランプ、第3停止ボタン色、リールフラッシュ、次回予告、PUSH連打、リール逆回転、モード別BGM
- 液晶背景：ステージごとの景色と動くパーティクル（星、火の粉、落雷、桜吹雪、雨、火花）
- キャラボイス（キャラ×場面ごとに音声を登録できます）
- 解析サイト風のページ（スペック表、フロー図、通常時・ATの抽選値、演出の期待度、設定示唆）
- 設定1〜6と設定示唆、データカウンター、スランプグラフ、オート
- 「キャラ画像」から自分の画像を登録できます（その端末にだけ保存されます）
- 「メニュー → 効果音・BGMを登録」から、他のAI（Suno、ElevenLabsなど）で作った音を登録できます。各音のプロンプトもコピーできます
